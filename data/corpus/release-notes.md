# Harbor 2.4 release notes

> Fictional Northstar Analytics demonstration document.

Status: RELEASED October 20, 2026. Harbor 2.4 added import-log filters, workspace-level API token expiration warnings and clearer CSV row-validation messages. Existing pricing and refresh frequencies were unchanged.

Token expiration warnings appear fourteen days before expiration. Admins and Owners receive the warning; Viewers do not. The import-log filter can isolate skipped rows, expired tokens or schema-change pauses. It does not automatically repair those failures.

Planned but not released: scheduled PDF email delivery and SCIM provisioning. Roadmap items are not available product features, have no committed release date, and should not be promised to customers.
