# Dashboard sharing and exports

> Fictional Northstar Analytics demonstration document.

Dashboards can be shared with members of the same workspace. Public anonymous links are not supported. Viewers can read shared dashboards, while Analysts and higher roles can edit dashboards when dataset permissions allow it.

CSV and PNG exports are supported for Analysts, Admins and Owners with access to the data. Viewers cannot export raw data. Scheduled PDF email delivery is not available. To share with an outside collaborator, invite that person to the workspace and assign the minimum required permissions.

A dashboard link does not override dataset restrictions. If a collaborator sees Access denied, an Admin should check both workspace membership and access to every dataset used by the dashboard.
